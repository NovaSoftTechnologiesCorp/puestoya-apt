# PuestoYa para Linux (apt)

Repositorio apt de [PuestoYa](https://mipuestoya.com) para Ubuntu y Debian (amd64).

```sh
curl -fsSL https://novasofttechnologiescorp.github.io/puestoya-apt/instalar.sh | sudo sh
sudo apt install puestoya
```

Las actualizaciones llegan con `sudo apt upgrade`. Lo publica el workflow `linux-deb` del repo de la app; no se edita a mano.
